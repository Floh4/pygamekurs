## Pygame Setup und .venv

### WICHTIGER HINWEIS! Sobald euer Mauszeiger in der nächsten Zeile ist, läuft der Befehl. NICHTS EINTIPPEN!

## Ordner "pygame-kurs-test" in VsCode öffnen

Ihr können den Ordner mithilfe von Rechtsclick auf den Ordner und dann auf "öffnen mit Vscode" in diesem Programm öffnen

Öffnet ein neues Terminal in Vscode und kopieren sie diesen command in das Terminal:

### 1

Zuerst diesen Befehl in das Vscode Terminal eingeben:

    python -m venv .venv

### 2

Danach CTRL + SHIFT + p eingeben und anschließend "Python: Select Interpreter" suchen anschließend müsst ihr dann den Python Interpreter auswählen wo hinten noch "(.venv)" steht

### 3

Dann müsst ihr auf den Mülleimer oben rechts **Vom Terminal** klicken.
Danach entweder auf oben links zwischen "Run" und "Help" klicken oder einfach CTRL + SHIFT + ö

### 4

Zuletzt Diesen Befehl in eurem Terminal ausführen

    pip install pygame

Nun seit ihr mit dem Installieren fertig und könnt main.py ausführen wobei ihr keine Fehler bekommen solltet.
