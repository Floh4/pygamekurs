# Python Kurs Starter

Alle Sachen die ihr braucht fur unseren *Python Einstieg Kurs*

## Downloaden von unserem github Repo

Geh auf Code und drück dann unten auf "Download ZIP". Oder drück auf den Download link

Hier ist der Download-Link: <https://github.com/Floh4/pygamekurs/archive/refs/tags/release-test.zip>

Entpacke den Ordner dann dort wo du Arbeiten willst

## Ordner "pygame-kurs-test" in VsCode öffnen

Ihr können den Ordner mithilfe von Rechtsklick auf den Ordner und dann auf "öffnen mit Vscode" in diesem Programm öffnen

Wenn ihr nun in vs code seid, solltet ihr die readme, den Aufgaben Ordner und den Code Ordner sehen

### Venv setup und pygame in venv installieren

## 1

Geh nun in den Code Ordner dann src dann vorlage.py

## 2

Drück *ctrl* oder *strg* + *shift* + *p*

Suche nun nach "Python: Select Interpreter" und drück drauf

## 3

Drück "+ Create Virtual Environment" und dann "venv" 

## 4

Wähl alles was über python3.6 (am besten über python3.13.14) ist

## 5

Dann sollte da stehen wie der Ordner(fürs venv) heißen soll --> Einfach *Enter* 

## 6

Drück auf "Search 'PyPI' packages" 

## 7

Such nach "pygame" und mach ein häkchen dran

Dann drück "Ok" und warte

### Teste ob es funktioniert

geh in die vorlage.py datei und drück oben rechts auf den `▷` Run Python File

Nun sollte im Terminal "Es funktioniert!" stehen
